# 使用说明（安装后）

## 1. 启动面板

安装并重启 DSH Desktop 后，在界面**左下角**出现蓝色圆形 **「法」** 浮标。点击弹出面板。

## 2. 登录（一次，会话保持）

面板 → 「① 登录 / 会话」：

1. 页面内嵌了经过本机网关转发的法信登录页（地址栏形态：`http://127.0.0.1:<port>/faxin-gw/login.aspx`）。
2. 输入你的法信**账号与密码**（也可以走页面提供的短信验证码/扫码方式，以官网为准）。
3. 若出现验证码/滑块等安全校验，**人工完成这一次**即可。
4. 点「我已登录，验证会话」，右上角状态变为绿色「已登录 · N cookie」。

之后（含 DSH 重启后一段时间内）所有 `mcp__faxin__*` 检索工具都直接复用该会话。

> 兜底：若内嵌页无法使用，用普通浏览器登录 www.faxin.cn，把请求头里的 `Cookie:`
> 整行复制，粘贴到面板文本框并「导入 Cookie」；或直接调用工具
> `faxin_import_cookies`。

## 3. 让 AI 用这些工具

工具名为 `mcp__faxin__*`，例如：

- `mcp__faxin__check_login` —— 会话状态
- `mcp__faxin__search_law` —— 法律法规结构化检索
  - `keyword` 必填；`timeliness`：current/invalid/modified/pending
  - `lib`：central/local/all
- `mcp__faxin__get_tiao` —— 法规名 + 条号 → 条文（例：law=民法典，tiao=680 或 第六百八十条）
- `mcp__faxin__search_case` —— 裁判规则库（需账号权限）
- `mcp__faxin__search_lib` —— 专题库（gjty/xgk/amk/flqk/flsy/lf/sf）
- `mcp__faxin__search_outline` / `mcp__faxin__get_outline` —— 法信大纲概念
- `mcp__faxin__get_detail` —— gid 详情全文（可选 `tiao` 精确取条）
- `mcp__faxin__import_cookies` —— 手动导入 Cookie

例如你可以直接对 AI 说：
> “用 mcp__faxin__get_tiao 查一下《中华人民共和国民法典》第六百八十条，
> 并说明它的禁止高利贷规定；再查 2024 年 1 月 1 日仍现行有效的相关司法解释。”

## 4. 数据位置

- 会话 Cookie：`C:\Users\<你>\.dsh\faxin-search\session.json`
- 删除即退出登录（或面板「清除本地会话」）。

## 5. 环境变量（可选）

| 变量 | 默认 | 说明 |
|---|---|---|
| `FAXIN_BASE_URL` | `https://www.faxin.cn` | 法信入口 |
| `FAXIN_DATA_DIR` | `%DSH_HOME%/faxin-search` | 会话/状态存放目录 |
| `FAXIN_HTTP_TIMEOUT_MS` | 30000 | 单次 HTTP 超时 |
| `FAXIN_MAX_RESULTS` | 20 | 检索默认返回条数 |
